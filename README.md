# 工作流程管理系統

內部工作流程管理系統的需求規格與可點擊原型。

## 內容

- `prototype/index.html` — 可點擊 HTML 原型（登入、流程看板/待辦、案件詳情/推進、流程定義設計器、ISO 文件對應、專案管理甘特圖）。
- `docs/需求規格.md` — 需求規格書（Markdown，v0.3）。

## 主要功能範圍

- 四大流程：銷售、系統導入、環境建置、客製化（需求變更）。
- 共通：流程自訂、表單與產出、作業範本附檔、附件/連結（SharePoint/OneDrive）、行事曆遞延、權限綜覽。
- 帳號登入：整合 Microsoft 365（Microsoft Entra ID SSO）。
- 專案管理：以專案串接各流程，甘特圖時間軸呈現進度與延遲/超前，專案行事曆排除日，簡報模式。
- ISO 27001：流程表單對應文件化需求。

> 原型資料為示意，互動皆為前端模擬，供功能方向確認之用。
